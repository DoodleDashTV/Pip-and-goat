# Visual acceptance criteria — Justin’s next review

These are objective checks for the next human review. Passing a script is not visual approval.

## Pip must show

| Check | Front | 3/4 | Side | Back |
| --- | --- | --- | --- | --- |
| Bright yellow-chartreuse, not mustard/olive | required | required | required | required |
| Cream-yellow cheeks / lower face | required | required | required | n/a |
| Exactly three coral crest feathers, center tallest | required | required | required | required |
| Wings shoulder → lower belly / upper thigh | required | required | required | required |
| Layered, pointed, symmetrical wings | required | required | required | required |
| Teal scarf + teal satchel + copper spiral | required | required | required | strap only |
| Strap over character-right, bag on character-left | required | required | required | strap path |
| Three forward toes + planted rear hallux | required | if visible | required | required |
| Large green eyes, friendly girl-character face | required | required | required | n/a |

Fail if: muddy brown/green body, stubby or shredded wings, two-feather profile crest, reversed satchel, missing hallux, crossed/dead eyes.

## Goat must show

| Check | Front | 3/4 | Side | Back |
| --- | --- | --- | --- | --- |

## Shared fail conditions

- Dramatic lighting, crop, or grading used to hide a mismatch
- Any GLB / Prism / Hunyuan / kitbash treated as canon
- Canonical `production-library/` replaced
- Retopo, groom, or rig started without Justin’s approval
