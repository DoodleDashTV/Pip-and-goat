# Pip replacement intake inbox

Uploaded Pip files land here as **replacement candidates**.

- Originals are copied unchanged and made read-only.
- ZIP packages are extracted beside the original, never into it.
- Nothing here is canon, theatrical-bound, or production-library.
- Inbox binaries are local-only and are not committed.

Run:

`scripts/tivvlejoy/ingest-next-pip.sh /path/to/pip_model`
