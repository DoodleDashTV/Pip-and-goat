# Environment requirements (document only — not this pass)

Do not rebuild meadow, creek, forest, cave, or VFX in this character pass.
These notes come from the VIDEO2 catalog, with VIDEO1 as supporting context.

| Need | Catalog observation | Later pass must |
| --- | --- | --- |
| Forest depth | Tall trunks, tunnel path, mist, canopy shadow | Read as a deep woods, not a flat card |
| Trail construction | Dirt, stones, moss, ferns, mushrooms | Hold a walkable center line |
| Blue footprint effects | Emissive cyan; four-toe, five-toe, or puddle variants | Pick one child-safe print language after measurement; not character feet |
| Crystal lighting | Purple crystals in VIDEO1 cave / portal | Light characters without dyeing cream/yellow albedo |
| Foreground framing | Ferns, trunks, signposts, lantern | Frame the pair without covering faces |
| Atmospheric perspective | Cool blue-green distance vs warm lantern | Keep depth at phone size |
| Adventure mystery | Path, prints, cave, sign | Mystery without a frightening creature rebuild |
| Warm/cool contrast | Lantern orange vs night teal / print cyan | Keep both; do not flatten to one grade |

Non-goals for the later env pass until Justin says otherwise:

- Copy Kling watermarks
- Copy generated sign lettering
- Rebuild the monster or watching-eye creature as a production character
- Replace canonical meadow/creek/map during the character pass
