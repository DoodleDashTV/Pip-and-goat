# TivvleJoy StageGraph V1

StageGraph replaces free-form scenery assembly with evidence-gated production. A successful process, Blender launch, geometry check, or file upload is technical evidence only. None of those events constitutes visual approval.

## First active workstream

The first certification candidate is `SRC_FOREST_STYLISED_ECOKIT` (`Stylised EcoKit.zip`). Its source digest, two large native `.blend` libraries, and 1,134 extracted textures already have zero-cost receipts. It is isolated from the failed multi-pack V4 scene so the studio can prove that one purchased pack can reproduce its advertised quality before combining environments.

The initial sequence is:

1. Lock the exact source digest.
2. Materialize every archive member without size-based silent skipping.
3. Open the native `.blend` in Blender 4.3.x.
4. Run the read-only dependency audit.
5. Block on missing images, libraries, fonts, caches, node groups, material outputs, or skipped archive members.
6. Only after a clean audit, request a fresh authorization for exactly one vendor-reference frame.
7. Compare the rendered frame with the vendor reference.
8. Record a human approval or rejection tied to the image SHA-256.
9. Create the TivvleJoy 9:16 beauty frame only after the vendor reference passes.

No video encode is allowed in this workstream.

## Character boundary

Pip and Goat remain `WAITING_FOR_ARTIST_RIGS`. No synthetic rig receipt, placeholder character, or old model can satisfy `PIP_RIG_APPROVED` or `GOAT_RIG_APPROVED`. Character implementation begins only after the delivered files are hashed, audited, rendered, and explicitly approved.

## Production truth

`PRODUCTION_READY` is earned only after the full gate sequence ends in `BATCH_10_QC_PASS`. The prior labels `GEOMETRY_PASS`, `BLENDER_RENDERED`, `WORKER_COMPLETE`, and `VISUAL_PROOF_COMPLETE` cannot satisfy a visual gate.

The final 60-second render remains prohibited until scenery, stage, both rigs, dialogue performance, animatic, per-shot beauty stills, render preflight, and an explicit final-render authorization all pass.
