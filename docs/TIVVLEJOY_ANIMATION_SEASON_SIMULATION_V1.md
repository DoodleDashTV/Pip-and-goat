# TIVVLEJOY_ANIMATION_SEASON_SIMULATION_V1

Uses the existing 60-episode / 720-shot season fixture.

Synthetic Pip and Goat capability fixtures stay:

- `SYNTHETIC`
- `NOT HUMAN APPROVED`
- `NOT REAL PRODUCTION RIG`

The simulation answers:

- shots plan-ready
- shots blocked by Pip rig
- shots blocked by Goat rig
- shots needing voice timing
- low-confidence viseme shots
- locomotion / prop-interaction counts
- continuity warnings
- animation QC blockers
- reusable action-plan count
- cache hit estimate
- animation batch count

It also covers flip, version-change, voice-change, map-handoff, locomotion-stress, and dialogue-performance scenarios without executing Blender.
