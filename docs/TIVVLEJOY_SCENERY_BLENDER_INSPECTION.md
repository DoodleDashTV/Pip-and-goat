# TivvleJoy isolated Blender inspection

Checkpoint: `TIVVLEJOY_SCENERY_BLENDER_INSPECTION_V1`

The 14 immutable purchase-site downloads remain unchanged in private Preview storage. Blend metadata may only be recorded on a temporary read-only copy using factory startup, disabled automatic script execution, a network namespace, and a strict timeout.

The worker records scenes, collections, objects, meshes, materials, images, cameras, lights, armatures, animations, Geometry Nodes, linked libraries, missing images, and triangle counts. It never saves, normalizes, approves, or commits licensed bytes.

Blender 4.2 is unavailable in this agent environment. No source was opened and blend-specific results remain `inspection_blocked`; counts were not invented.
