# TIVVLEJOY_SCENERY_REAL_LIBRARY_CONVERGENCE_V1

Convergence feeds existing village, forest, sky/HDRI, mountain, and tavern
metadata through the inspection evidence model without re-reading commercial
bytes when trustworthy immutable evidence already exists.

Policies:

- Botaniq Full 7.2.0 remains `NOT_ACTIVATED`.
- Geo-Scatter companion packs remain `OPTIONAL_NOT_INTEGRATED`.
- Gaffer remains `INSTALL_LATER` / optional. Native lighting is baseline.
- Physical Starlight remains optional and inactive.
- World shader packages may be `MATERIAL_LIBRARY` or
  `PROCEDURAL_MATERIAL_SOURCE`. They are not environment geometry and stay
  execution-disabled.
- HDRI ownership is not redistribution permission.

If private source bytes are unreachable, the report records the exact
materialization blocker and continues with synthetic/static validation.
Human approvals stay 0 until a real reviewer issues a receipt.
