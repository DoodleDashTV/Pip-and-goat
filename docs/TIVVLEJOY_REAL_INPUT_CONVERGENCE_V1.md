# TIVVLEJOY_REAL_INPUT_CONVERGENCE_V1

Stacked on Draft PR #86. This system turns **existing real inputs** into
verified production evidence and compiles an honest first-episode preflight
for EP012 (The Bakery Map).

It does **not** expand synthetic architecture for its own sake.

## What is real vs synthetic

- A listed private object is not an inspected source.
- A hashed object identity is not a production asset name.
- A static inspection is not human approval.
- A synthetic voice fixture is not a real receipt.
- A synthetic rig playbook is not a production rig.
- Synthetic success cannot hide a real blocker.

## Pipeline

```
private R2 list (read-only)
→ hashed object inventory
→ receipt ↔ object matching
→ budgeted materialization
→ independent SHA-256
→ static inspection
→ evidence-backed logical children
→ visual review queue
→ EP012 preflight + gap ledger
```

Filenames are operator labels only. They are never production identity.
