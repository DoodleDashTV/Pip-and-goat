# TIVVLEJOY_DIRECTING_SYSTEM_V1

Director software converts episode intent into beats, shot language, staging,
performance notes, lighting/VFX intent, editorial timing, and a Director
Package.

This layer does not execute Blender, approve scenery, admit rigs, or launch
paid render.

Stacked on Draft PR #85 scenery inspection. Preview consoles:

- `/director-control`
- `/editorial-control`
- `/dailies`
- `/production-control`
