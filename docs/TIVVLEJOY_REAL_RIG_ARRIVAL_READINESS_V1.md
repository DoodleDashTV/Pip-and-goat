## Intake

- SHA-256 required
- Size cap and minimum plausible size
- Extension allow-list: `.blend`, `.glb`, `.fbx`
- Duplicate hash rejected
- Prior versions are never overwritten
- Never auto-approved

## Playbook

`NOT_PRESENT → STORED → HASH_VERIFIED → INSPECTION_REQUIRED → CAPABILITY_CHECK → VISUAL_REVIEW → HUMAN_APPROVAL_REQUIRED`

A synthetic fixture can walk the playbook for software proof. It cannot reach
real approval.
